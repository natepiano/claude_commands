# Renamed units go through `/showrunner:rename_unit`

Read `~/.claude/commands/showrunner/rename_unit.md` in full and run it with the arguments this command
was given, unchanged: `$ARGUMENTS`. It runs in the showrunner session. A unit cannot rename itself,
since the rename stops and relaunches it.
