**Arguments**: `$ARGUMENTS` — `[<scope>] <filename>`

This is `/new_style` for a local rule. Read `~/.claude/commands/new_style.md` and follow it with the arguments `local <scope> <filename>`, or `local <filename>` when no scope is given.

A local rule needs the same frontmatter as a global rule. Without `tier`, the rule catalog fails to load.
